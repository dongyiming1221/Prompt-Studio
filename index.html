ABOUT THIS VERSION

当前版本说明

免费本地模式

提示词在浏览器中生成，记录保存在当前设备的本地存储中，不需要注册或 API Key。不同设备之间不会自动同步。

AI 增强模式（后续接入）

需要配置安全的服务端 API 代理。正式上线时不能把模型 API Key 写在网页前端。模型供应商和费用需由站点运营者自行选择。

安装到手机

网站部署到 HTTPS 域名后，使用手机浏览器菜单中的“添加到主屏幕”即可。当前源码已包含 PWA 基础文件。

隐私

本地版本不会把输入内容发送到服务器。清除浏览器站点数据会同时清除本地历史记录。
